## Getting Started

### Build
```bash
cd /root/Qallow
rm -rf build
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cd build && make -j$(nproc)
```

### Run Individual Phases
```bash
# Phase 16: Constraint Validation
./build/qallow phase 16

# Phase 20: Result Synthesis
./build/qallow phase 20
```

### Run All Phases
```bash
../run_all_phases.sh
```
