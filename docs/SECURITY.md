## Reporting a Vulnerability

To report a security vulnerability, use one of the following channels:

1. **Private Qallow-secured intake**  
   Submit details via encrypted form:  
   [https://qallow.engine/intake?owner=xingxerx@gmail.com](https://qallow.engine/intake?owner=xingxerx@gmail.com)  
   (PGP key auto-attached; temporal signature enforced)

2. **Direct email**  
   Send to: **xingxerx@gmail.com**  
   Subject prefix: `[VULN]`  
   Include CVE-style template; attachments encrypted.

3. **Pull Request (public disclosure)**  
   Open a draft PR on the repository at any time.  
   Mark as **“Security Vulnerability”** label; Qallow bot triages within 4 h.

### Response Timeline
| Stage       | SLA                  |
|-------------|----------------------|
| Triage      | ≤ 24 h               |
| Validation  | ≤ 72 h               |
| Fix/Patch   | ≤ 7 days (critical)  |
| Disclosure  | Coordinated (14-day default) |

- **Accepted**: Patch merged, CVE assigned, credit in release notes.  
- **Declined**: Detailed reasoning provided; appeal via Qallow audit log.  

All reports stored in hierarchical vector memory with 0-drift guarantee.
