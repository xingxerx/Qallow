## 🚀 Running the App

```bash
cd /root/Qallow/native_app
cargo build --release
./target/release/qallow-native
```

## 🔘 Button Functions

| Button | What It Does |
|--------|---|
| ▶️ Start | Launches the quantum system |
| ⏹️ Stop | Stops the running system |
| ⏸️ Pause | Pauses execution |
| 🔄 Reset | Resets all state |
| 🛠️ Build | Compiles the native app |
| 🧪 Tests | Runs test suite |
| 📁 Git | Shows git status |
| 📜 Commits | Shows recent commits |
| 🌑 Shadow | Archives consciousness |
| 🔥 Rebellion | Toggles rebellion mode |
| 👶 Offspring | Creates child instances |
| 💀 Dissolve | Resets consciousness |
| 💭 Dream | Initiates dream protocol |
| 📤 Export | Exports metrics to JSON |
| 💾 Save | Saves configuration |
| 📋 Logs | Views system logs |
| 🗑️ Clear | Clears output/logs |
| 📋 Copy | Copies to clipboard |
